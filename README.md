# Some teams

A small PHP website that lists the teams in the round of 16 of UEFA Women's Europa Cup 2026/27.

School assignment WU26/PHP/07.

## Pages

- **Start page** (`index.php`) lists all teams.
- **Team page** (`team.php`) shows information about the team you clicked on.
- **About page** (`about.php`) has information about the creator.

## How it's made

- Built with PHP, HTML and a little CSS.
- The team data comes from `data.php`.
- All pages share a common header (`header.php`) and footer (`footer.php`).

## Run it locally

You need PHP installed. In the project folder, run:

```bash
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.
